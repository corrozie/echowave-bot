# Echo Wave Bot

Telegram-бот EchoWave для музыкантов: помогает определиться с запросом, собирает анкету для разбора проекта и отправляет PDF-гайд «Почему твою музыку забывают».

Написан на Python с использованием aiogram 3 и python-dotenv.

## Запуск

1. Установите зависимости: `pip install -r requirements.txt`.
2. Укажите токен своего Telegram-бота в файле `.env`: `BOT_TOKEN=ваш_токен`.
3. Запустите бота: `python main.py`.
4. Отправьте боту команду `/start` в Telegram.

PDF-гайд должен находиться рядом с `main.py`.
